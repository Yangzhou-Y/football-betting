## 一、合约层改动（FootballBetting.sol）

### 1.1 允许重复投注 + 切换选项

**问题**：用户每场只能投注一次，无法追加或修改。

**修改**：重写 `placeBet` 函数。

| 场景 | 旧行为 | 新行为 |
|---|---|---|
| 首次投注 | 正常投注 | 不变 |
| 相同选项再投 | `revert: already placed a bet` | 累加金额 + 追加奖池 |
| 切换不同选项 | `revert: already placed a bet` | 旧金额从旧池移除 → 加入新池，差额结算 |

### 1.2 差额结算

**问题**：切换选项时旧 USDT 已留在合约中，`transferFrom` 又全额扣款，用户多付。

**修改**：

| 新 vs 旧 | 行为 |
|---|---|
| 新 > 旧 | `transferFrom` 差额补收 |
| 新 < 旧 | `transfer` 退回差额 |
| 新 == 旧 | 零转账，纯奖池移动 |

### 1.3 新增 cancelBet 函数

投注期内可撤回投注：从奖池移除全部金额 → 删除投注记录 → `transfer` 退回 USDT。带 `noReentrancy` + `whenNotPaused`。

### 1.4 修复 previewReward 整数下溢

**问题**：当 `winningPool` 接近 `totalPool` 时，`distributablePool - winningPool` 在 `unchecked` 下溢出，返回巨大数字。

**修复**：改用与 `claimReward` 一致的公式 `amount * distributablePool / winningPool`。

### 1.5 新增 allowDraw 字段

- Match 结构体新增 `bool allowDraw`（挤入槽 5，不增加 Gas）
- `createMatch` 新增 `bool allowDraw` 参数
- `placeBet` 新增检查：`allowDraw=false` 时投注平局 revert

### 1.6 新增 matchName 字段

- Match 结构体新增 `bytes32 matchName`（独占用新槽，+1 SSTORE）
- `createMatch` 第一参数改为 `matchName`
- MatchCreated 事件新增 matchName 字段
- 空名称检查：`require(matchName != bytes32(0))`

### 1.7 新增内部辅助函数

`_addToPool` / `_removeFromPool` 封装奖池 + totalPool 增减，在 `placeBet`、`cancelBet`、`recordResult` 中复用。

## 四、Bug 修复

| # | 现象 | 根因 | 修复方式 |
|---|---|---|---|
| 1 | 中文队名乱码 | viem `stringToHex` 中文编码异常 | 改用 `TextEncoder`/`TextDecoder` |
| 2 | 暂停状态显示错误 | `useState(false)` 本地状态刷新丢失 | `useReadContract("paused")` 链上读取 |
| 3 | 交易后数据不刷新 | 无确认后刷新机制 | `useWaitForTxAndRefresh` → `invalidateQueries` |
| 4 | USDT 余额不足仍可投注 | 前端未检查余额 | `balanceOf` 查询 + 按钮置灰 |
| 5 | 切换投注选项旧金额消失 | `transferFrom` 全额扣款 | 差额结算 |
| 6 | 录入赛果弹窗被遮挡 | 弹窗 z-50 与 navbar 同级 | `z-[9999]` + `createPortal` |
| 7 | EVM 时间无法回退 | `evm_setNextBlockTimestamp` 不能设过去 | `Math.max(realTime, blockTime) + 1` |
| 8 | previewReward 显示巨大数字 | `loserPool` 整数下溢 | 改用 `amount * distributablePool / winningPool` |
| 9 | MetaMask 连接失败 | 注册未完成 + 双钱包冲突 | 恢复助记词跳过注册、禁用非活跃扩展 |
| 10 | 钱包导入 USDT 余额显示 1100 亿 | Rabby 小数位识别错误 | Navbar 前端直读合约余额 |
| 11 | 切换账户后投注成功提示残留 | 组件未因地址变化重置 | `key={bet-${address}}` + `lastBetAccount` ref |
| 12 | 录入弹窗首次点击 UI 异常 | `PageTransition` opacity 动画干扰 fixed 定位 | `createPortal` 到 `document.body` |
| 13 | 钱包取消交易后 pending toast 不消失 | `useWriteContract` error 未被监听 | 监听 `error` + parseContractError + dismiss pending |
| 14 | 多个取消 toast 堆叠 | 多个组件同时触发 toast | `useState<ToastItem \| null>` 一 slot 模式 |
| 15 | 国旗 emoji 不渲染（Windows） | Windows 不支持 Unicode flag 序列 | 改用 flagcdn.com CDN 图片 |
| 16 | 开启/关闭赛事没有取消提示 | MatchManagement 未监听 error | `adminError` + toast |
| 17 | MetaMask 导入私钥报错 | 粘贴了 `0x` 前缀 | 去掉前缀重新导入 |
