## 一、WalletConnect 问题最终定论

### 1.1 前情

昨天在 `fix/mobile-WalletConnect` 分支上做了 20+ 个 commit 排查 WalletConnect 桌面端扫码不稳定问题。核心发现：
- RPC URL `/rpc/conflux-testnet` 改为 `https://evmtestnet.confluxrpc.com` 后，连接流程正常工作
- 但 WalletConnect 连接后偶发"无断开按钮、无法签名"
- F12 控制台零报错

### 1.2 今早的收尾排查

在昨天基础上继续尝试了 4 个方案，均无法稳定复现：

| 方案 | 结果 |
|------|------|
| 独立 wagmi connector + 手动 rkDetails | 按钮不出现在 RainbowKit modal |
| 独立按钮 + `connectAsync` + `reconnect` | 连接成功但状态不更新 |
| `connectorsForWallets` + `projectId: ""` 消除 Core 双重初始化 | 状态仍不更新 |
| `showQrModal: false` 让 RainbowKit 管控 | 已知会白屏（React 19），未测 |

### 1.3 根因确认

咨询项目发起人后确认：**MetaMask App 的 WalletConnect 是实验性功能**（App 内标注为 "Experimental"）。连接不稳定、session 状态回传不可靠都是 MetaMask 侧问题，非 dApp 代码问题。

链上交易的核心用户通常使用 Chrome + MetaMask 拓展直连，不需要 WC 扫码功能。

### 1.4 分支处理

- `fix/mobile-WalletConnect` 分支回退到 `7464e3c`（昨天 RPC URL 修复后的状态），保留完整实验代码供将来 MetaMask WC 转正后继续
- RPC URL 修复 cherry-pick 到 main

## 三、`fix/mobile-ui2` 分支 — 移动端 UI 精细化

### 3.1 统计卡片改为横排

**问题**：手机端"赛事总数""累计奖池""投注中"三个卡片上下堆叠，占用太多纵向空间。

**修复** (`762c71f`)：

| 属性 | 旧 | 新 |
|------|-----|-----|
| grid 列数 | `grid-cols-1 sm:grid-cols-3` | `grid-cols-3` |
| 间距 | `gap-4` | `gap-2 sm:gap-4` |
| 标题字号 | `text-sm` | `text-xs sm:text-sm` |
| 数值字号 | `text-2xl` | `text-base sm:text-2xl` |

### 3.2 中英混排数字基线对齐

**问题**：Geist 字体（仅含拉丁字符）与系统中文字体的基线不一致，数字明显向下偏移。

**修复** (`294a397`)：

1. body 字体栈加入 CJK 优先字体：
   ```css
   font-family: var(--font-geist-sans), "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", Arial, sans-serif;
   ```

2. `.tabular-nums` 类增加微调：
   ```css
   .tabular-nums {
     vertical-align: -0.06em;
   }
   ```

PingFang SC / Microsoft YaHei 同时包含中英文，设计师已调好基线。数字额外上移 0.06em 消除残余偏差。

### 3.3 比赛时间恢复完整显示

UI 修好后时间不会超出卡片边界，`formatTimeShort` 不再需要，恢复为完整的 `formatTime` 显示。

### 3.4 奖池文本不换行

MatchCard 奖池行加 `whitespace-nowrap`，防止 "奖池：XXX USDT" 在窄屏上折行。

### 3.5 禁用手机端缩放

Next.js App Router 通过独立 `viewport` 导出禁用：

```ts
export const viewport: Viewport = {
  width: "device-width",
  initialScale: 1.0,
  maximumScale: 1.0,
  userScalable: false,
};
```

### 3.6 MetaMask App 内置浏览器钱包连接

手机端 MetaMask App 内置浏览器注入 `window.ethereum`，但 RainbowKit 默认在移动端过滤 injected wallet。使用 `connectorsForWallets` + 自定义 MetaMask 钱包定义（含 `_metamask` 三级严格检测），让 MetaMask 按钮在所有平台出现。
