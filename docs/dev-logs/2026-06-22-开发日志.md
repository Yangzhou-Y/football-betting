## 二、合约层改动（FootballBetting.sol）

### 2.1 `reopenMatch` 防止资不抵债（H-1 / H-2）

**问题**：若用户已领奖后管理员调用 `reopenMatch` 回退重结算，已领奖用户保留资金 + 新赢家无法兑付 → 合约破产。

**修复**：新增 `mapping(uint256 => uint256) public matchClaimCount`，`claimReward` 中递增，`reopenMatch` 检查 `matchClaimCount[matchId] == 0`，有人领奖则禁止回退。

### 2.2 `placeBet` 添加 `noReentrancy` 修饰符（M-1）

**问题**：`placeBet` 调用 `usdt.transferFrom` 但缺少防重入锁，与其他函数不一致。

**修复**：添加 `noReentrancy` 修饰符，增强防御深度。

### 2.3 提取 `_calculateFee` / `_calculateReward` 共享函数（M-2 / L-5）

**问题**：手续费和奖励计算逻辑在 `recordResult`、`claimReward`、`previewReward` 中重复，维护成本高。

**修复**：新增 `_calculateFee(Match storage m, Result r)` 和 `_calculateReward(Match storage m, Bet storage userBet)` 内部函数，三处调用点统一。

### 2.4 移除无效的 `unchecked` 包裹（M-3）

**问题**：`unchecked { _addToPool(m, betOn, betAmount); }` 不会传递到内部函数，注释声称省 2-3% gas 不实。

**修复**：移除所有无效的 `unchecked` 包裹，仅在 `_calculateFee` 的 `pool * platformFeeRate / 10000` 处保留有效 unchecked。

### 2.5 移除 `recordResult` 的 `noReentrancy`（L-2）

**问题**：`recordResult` 无外部调用，`noReentrancy` 浪费约 5,000 gas。

**修复**：移除修饰符。

### 2.6 修复 storage layout 注释（L-1）

**问题**：注释标注 6 槽但实际为 7 槽，遗漏了 `matchName` 字段。

**修复**：更新布局图为 7 槽，包含所有字段。

### 2.7 `deleteMatch` 改为左移递进模式

**问题**：旧版 swap-and-pop 将最后一场移入被删位置，用户要求所有后续比赛依次递进补位。

**修复**：改为 `for` 循环左移——删除 #2 后，#3→#2、#4→#3、#5→#4，`matchCounter` 减一。安全约束：被移动的比赛也需处于 `Created` 状态且 `totalPool == 0`。

### 2.8 `deleteMatch` 增加 `totalPool` 检查（L-7）

**修复**：添加 `require(m.totalPool == 0)`，防止投注后误删。

### 2.9 新增 `autoClose` 公开封盘函数

**问题**：比赛到达截止时间后仍需管理员手动封盘。

**修复**：新增 `autoClose(uint256 matchId)` 函数，任何人可调用，要求 `status == Open && block.timestamp >= deadline`。配合前端自动检测实现无人值守封盘。

### 7.2 公网访问（Cloudflare Tunnel）

先启动生产服务器，再开隧道（**两个终端各跑一个**）：

```bash
# 终端 A：构建并启动生产服务器
cd frontend
npm run build && npm run start -- -p 3000

# 终端 B：开隧道（无需登录，自动生成公网域名）
npx cloudflared tunnel --url http://localhost:3000
```

隧道启动后终端会打印公网地址：`https://<random>.trycloudflare.com`（每次重启地址会变）。

**注意事项**：
- 生产服务器端口 3000 被占用时，需先 `taskkill /F /PID <进程号>` 杀掉旧进程
- 开发服务器（`npm run dev`）不可用于隧道——Turbopack 的 WebSocket HMR 会拦截外部请求报 `Unauthorized`
- Cloudflare Tunnel 免费版无 SLA，测试用途可用，生产环境建议用 Named Tunnel 或 Vercel/Netlify 部署

### 7.3 上线步骤

1. `.env` 填入 `PRIVATE_KEY`
2. 水龙头领 CFX：https://efaucet.confluxnetwork.org
3. `npx hardhat run scripts/deploy.ts --network confluxTestnet`
4. 取消 `config.ts` 第 6、22 行注释
5. `cd frontend && npm run build && npm run start -- -p 3000`
6. 另开终端：`npx cloudflared tunnel --url http://localhost:3000`
7. 将隧道地址发给测试人员

## 十、已知限制

1. Cloudflare Tunnel 地址每次重启会变，共享给测试人员后不能关隧道，且目前隧道还存在一定问题，外部无法正常访问👌
2. MetaMask 不支持 Conflux eSpace（XChain Swaps 报错拦截发送），建议用 Rabby Wallet👌
3. `autoClose` 依赖前端页面加载触发，若无人访问首页/赛事页则不会自动封盘👌
4. `deleteMatch` 左移递进要求被移动的比赛也无投注，仅适用于删除末尾连续的 Created 状态比赛👌
5. 游客模式使用 Conflux 公共 RPC，高并发下可能被限流👌
